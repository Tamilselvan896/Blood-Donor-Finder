# 🩸 Blood Donor Finder

A full-stack MERN application that helps users find blood donors quickly and easily. Users can register, log in securely, manage their profile, and search for blood donors by blood group and location.

---

## 🚀 Live Demo

Frontend: https://blood-donor-finder-1-ltts.onrender.com

Backend API: https://blood-donor-finder-84ha.onrender.com

---

## ✨ Features

- User Registration
- Secure Login with JWT Authentication
- Password Encryption using bcrypt
- Search Blood Donors
- User Profile Management
- MongoDB Database
- Responsive User Interface
- REST API

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Tamilselvan896/Blood-Donor-Finder.git
```

### Install Backend

```bash
cd backend
npm install
npm start
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```
